# Project context

Before doing anything else in this repo, **read `ROADMAP.md` in the repo root.** It has the
project goal, the full phase-by-phase plan, tech decisions already made (and why), and a
"Current Status" section at the bottom telling you exactly what's done, what's verified, and what
to build next. Do not re-derive decisions already recorded there, and update it as you go — it's
the source of truth for this project, not conversation memory.
